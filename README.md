# Branchborne Gem Quest

Bejeweled / Gems of War style match-3 with a web-development learning twist. Match tech gems, clear side quests, and play a pathway through to Senior / class Expert.

The playable cabinet was copied from the standalone player in [matthummel-pa/matthummel-pa](https://github.com/matthummel-pa/matthummel-pa) (`game/`).

## Run locally

No install step. From the repository root:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Open `http://127.0.0.1:4173/`. Pick a pathway on the start screen, then swap adjacent gems.
